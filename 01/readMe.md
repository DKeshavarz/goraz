
# GoRaz - Module 1: Foundations

Welcome to Module 1! This is your first step toward becoming a Go developer. You'll learn the essential building blocks of the language.

## Topics

### Go Fundamentals & Project Setup
- What is Go and why use it
- Installation and setup
- Go Modules (`go mod init`)
- Your first Go program
- Variables, constants, and basic types (`var`, `:=`, `string`, `int`, `bool`)

### Control Flow
- `if` statements (including `if err != nil` pattern)
- `for` loops (C-style, while-style, infinite, `for range`)
- `switch` statements (expression and conditionless)

### Error Handling in Go
- The `error` interface
- Multiple return values with errors
- The `if err != nil` pattern
- Custom errors

### Functions
- Declaring functions
- Parameters and return types
- Multiple return values
- Named returns (use sparingly)
- Variadic functions (`...int`)
- `defer` for cleanup

### Data Structures
- Arrays (and why you won't use them much)
- **Slices** (`make`, `append`, `len`, `cap`, slicing)
- **Maps** (`make`, `delete`, "comma ok" idiom)

### Testing
- The `testing` package
- Test file naming (`xxx_test.go`)
- Writing test functions (`func TestXxx(t *testing.T)`)
- Table-driven tests
- Running tests with `go test`
